# Rugby Rooster Build Plan

This is the current roadmap, not permission to implement later milestones inside CCPP-001.

## Milestone Sequence

1. Application foundation - this task.
2. Detailed game rules and tested scoring engine.
3. Passwordless accounts and authorisation.
4. Fixture management and public fixture browsing.
5. Prediction sequence and submission locking.
6. Match-event capture, corrections, and live/final leaderboard scoring.
7. Subsequent league, venue, sponsorship, animation, quiz, and AI milestones.

## CCPP-001 Scope

Implemented:

- Meteor React TypeScript application at the repository root.
- TailwindCSS foundation styling.
- Lightweight route handling for public, admin, and not-found views.
- Documentation convention and initial system documents.
- Static verification commands for linting, formatting, and TypeScript.

Not implemented:

- Accounts or passwordless email links.
- Fixture administration or fixture data.
- Prediction forms, scoring, deductions, or validation.
- Match-event capture or leaderboard calculations.
- League management, prizes, sponsorships, Kaplay animations, quizzes, or AI reports.

## Roadmap Discipline

Future work should promote product decisions from unresolved to implemented only when a task supplies sufficient detail and verification. When a decision is missing, document the gap instead of filling it with assumptions.
